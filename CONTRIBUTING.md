# Contributing

Use synthetic data only. Do not submit personal catalogues, raw error logs,
account IDs, credentials, private source paths or private filenames. Report
problems with a minimal synthetic reproduction.

Propose format changes in an issue or pull request describing the use case,
privacy implications, compatibility impact and positive/negative examples.
Changes to the format require a new versioned specification and schemas; do not
rewrite an already published version. Test tooling changes with the full suite
and both examples using the commands in README.md.

Contributions are provided under the licence applicable to each file as described
in LICENSE. Please contribute only material you are entitled to license. No CLA
or formal standards body is established. Initial maintenance is by arcticflea;
OAF is an experimental independent specification, not a certified standard.
